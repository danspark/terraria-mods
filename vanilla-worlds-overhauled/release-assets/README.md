# Release artwork

`worldgen-reference.png` is an unedited minimap crop from the deterministic large world generated with numeric seed `882350129`. It was selected because one frame shows the mod's mountain scale, distinct biome materials, bridge, cave network, water, vegetation, and surface-to-Cavern verticality.

`icon-source.png` is original release artwork derived from that generated-world composition. The packaged file is `../icon.png` at tModLoader's required 80×80 size. The optional `icon_small.png` is intentionally omitted because tModLoader 2026.07.3.0 on Linux rejects custom small icons during its resource-conversion step.

## Reproduction brief

```text
Use case: stylized-concept
Asset type: square pixel-art game mod icon that remains immediately legible when reduced to 80 by 80 pixels.

Use Input Image 1 only as a visual, composition, and palette reference from the generated Vanilla Worlds Overhauled minimap. Create an original emblem, not a literal crop.

Primary request: depict two immense, distinct mountain peaks joined by one substantial timber-and-stone bridge over a deep valley. Cut one bold cave mouth and a bright blue mountain pool into the rock. Crown the upper slopes with a small white cloud belt and sparse green plants. Include subtle layered biome seams—stone gray, earth brown, desert gold, corruption violet, jungle green, and water blue—so the icon communicates a world-generation mod with many biomes.

Composition: centered, near-symmetrical twin-peak silhouette; the mountains and bridge fill most of the square; bridge is readable at thumbnail size; deep midnight-blue sky provides negative space; simplified large pixel clusters, strong contour, high contrast, no busy micro-detail.

Style: polished hand-authored 2D pixel art with minimap readability, crisp hard-edged pixels, coherent limited palette, slight atmospheric depth through flat color bands only.

Constraints: no words, letters, numbers, logos, game UI, characters, enemies, item sprites, watermark, border, fuzzy anti-aliasing, photorealism, or gradients. Do not reproduce the Terraria logo. Avoid tiny details that disappear at 80 pixels.
```
